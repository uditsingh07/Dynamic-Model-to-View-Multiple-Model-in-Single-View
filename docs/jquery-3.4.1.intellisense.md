# jQuery IntelliSense

This script provides IntelliSense support for jQuery in Visual Studio Code.

## Usage

To use this script, add the following line to your `settings.json` file:

{
    "javascript.intelliSense.enable": true,
    "javascript.intelliSense.jsFile": "path/to/jquery-3.4.1.intellisense.js"
}

## Configuration Options

The following configuration options are available:
### jsFile

* `jsFile`: The path to the IntelliSense script file.
