# jQuery IntelliSense

This script provides auto-completion and code snippets for jQuery functions, methods, and properties.

## Usage

To use this script, include it in your HTML file before the closing `<head>` tag:
html
<script src="scripts/jquery-3.4.1.intellisense.js"></script>
</head>


## Configuration Options

The script can be customized by passing options to the `$.intelliSense` function.
javascript
$.intelliSense(options);
