# jQuery Validate Unobtrusive

The jQuery Validate Unobtrusive plugin provides server-side validation for forms, ensuring data integrity and preventing form submission errors.

## Usage
javascript
$.validator({
  // validation rules
});


## Configuration Options
| Option | Description | Default Value |
| --- | --- | --- |
| showMessage | Show error messages on form elements | `false` |
| highlight | Highlight invalid fields with a CSS class | `.highlight` |
| success | Display a success message after validation is successful | `.success` |
