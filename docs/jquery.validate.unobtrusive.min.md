# jQuery Validate Unobtrusive

The jQuery Validate Unobtrusive plugin is a client-side validation library that integrates with ASP.NET MVC and other unobtrusive JavaScript frameworks.

## Features
- Validates form fields on page load and submission
- Supports various validation rules, including required, email, phone, URL, and more
- Integrates seamlessly with ASP.NET MVC and other unobtrusive frameworks
