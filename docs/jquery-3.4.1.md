# jQuery Library

The `jquery-3.4.1.js` file is a JavaScript library that simplifies DOM manipulation and event handling.

## Usage

To include the library in your project, simply link to it in your HTML file:
html
<script src="https://code.jquery.com/jquery-3.4.1.min.js"></script>
</html>

### Methods

* `.ajax()`: Makes an AJAX request.
* `.click()`: Attaches a click event listener.
* `.html()`: Sets the HTML content of an element.
